# Offline «أبو الياس» database — rules
- The offline «أبو الياس» Android app is a separate static build (`vite.local.config.ts`) that swaps `src/lib/local-mode.tsx`/server functions for `src/lib/local-db/*`: PGlite runs the cloud schema and triggers on the phone behind a PostgREST/auth shim, so every screen and financial rule stays identical without a server. It imports one admin export (`src/lib/abu-export.ts`) once and never syncs; persistence flushes to IndexedDB only after writes (reads stay fast). Never ship local-db code or overrides in the cloud build.
- Abu Elyas phone tools (`src/lib/local-db/holgen.ts`, `maintenance.ts`): Holgen .db vouchers import as immutable `posting_source=holgen` journal entries (negative=debit) so balances match Holgen; the new-year rollover keeps master data, clears operations, and posts one per-currency balanced opening entry plus opening box movements, requiring a backup first.
